## Typography
- **Headings:** Chivo (Bold 700 / Medium 500). Fallbacks: Archivo, system-ui.
- **Body:** Hanken Grotesk (400/500/600). Fallbacks: Source Sans 3, sans-serif.
- **Mono / labels:** JetBrains Mono (400/500/600).

## Type license shopping list (action required)
- **Chivo** — SIL Open Font License, free for commercial use (Google Fonts / Omnibus-Type). No purchase needed; self-host webfonts.
- **Hanken Grotesk** — SIL Open Font License, free (Hanken Design Co.). Self-host webfonts.
- **JetBrains Mono** — SIL Open Font License, free (JetBrains). Self-host webfonts.
> All three are OFL — no paid license required. Bundle the webfont files with the product and mirror them in the design-system repo.
