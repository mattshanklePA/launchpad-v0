One-line: Small metadata label for counts, categories, and keys — not for status (use `StatusPill` for on-track / alert / attention).

```jsx
<Badge tone="info">12 initiatives</Badge>
<Badge mono tone="basalt">GATE-3</Badge>
```

Tones: `neutral | basalt | info | amber`. Set `mono` for codes/keys (uppercase JetBrains Mono).
