One-line: Square icon-only button for toolbars and table rows; always pass a `label` for accessibility.

```jsx
<IconButton label="More actions"><MoreVertical size={18} /></IconButton>
<IconButton label="Fund" variant="primary"><Check size={18} /></IconButton>
```

Variants `ghost | secondary | primary`, sizes `sm | md | lg`. Same seat-down press as Button.
