# Keystone redesign mocks (Claude Design export, 18 Aug 2026)

Source of truth for the RD-* redesign issues. Numbered `NN *.dc.html` files are
the approved screens; `handoff/DIVERGENCES.md` explains where they depart from
the original brief; `handoff/png/` are thumbnails; `_ds/` is the design system
export (tokens identical to `app/styles/keystone/*.css` except the canvas,
which the mocks set to `--ks-chalk`); `assets/` are the brand marks.

Unnumbered boards (`Enterprise Dashboard v2/v3`, `Home - Command Center`,
`Intake Variant 1-3`, `Direction A *`, `01 Reviewer Submission Detail`,
`02 Portfolio Screens`) are earlier explorations. Where they conflict with a
numbered screen, the numbered screen wins. `Intake Variant 3` is referenced
only for the open state of the admin dropdown.

The `.dc.html` files are self-contained inline-styled HTML. Read the markup
for structure and copy; do not try to run `support.js`.
