Rules
  • A proposed value is always visually distinct from a settled one, and never pre-counted as complete.
  • Confirm and Change sit side by side at equal weight. Confirm is primary only because it is the common case, never because it is preferred.
  • The reason line is mandatory. No proposal ships without one.
  • An override asks for a note and keeps the original value visible in the record.
  • Silence is a state. When Plumb can't derive a value it says so rather than leaving a blank field.
